# Unity Scripting Course — Class Plan

## Course Overview

A 10-week introductory programming course for game developers using C# and Unity.
**Philosophy:** Fundamentals-first, reverse-engineer pedagogy — students experience a working product before dissecting how it's built.

---

## Course Structure

| Phase | Weeks | Focus |
|---|---|---|
| C# Fundamentals | 1–5 | Pure C# in Visual Studio (.NET console) |
| Unity Transition | 6–10 | Port logic into Unity using provided template |

---

## Pedagogical Approach

- Students are given a **working, playable template** first — they interact with it, then learn how it's built
- Always have something satisfying to look at and play with
- Understanding how things work is the *second* layer
- This is a **programming class**, not a Unity implementation class

---

## Key Projects

### Project 1 — Text Adventure Game (C# Console → Unity)
- Students start with a provided C# text adventure template
- Extend and customise the logic and data structures
- Focus: classes, structs, linked lists, inheritance, file I/O

### Project 2 — Unity Game
- Students start with a provided Unity template
- Extend with their own scripting: animations, 3D assets, game logic
- Same architectural thinking, now in an engine context

---

## Assessments

- **Midterm Exam 1** — Written/knowledge-based, tests scripting fundamentals
- **Midterm Exam 2** — Written/knowledge-based, tests data structures and OOP concepts
- *(Midterms are in-class to avoid grading finished game projects)*

---

## Core Concepts to Cover

- Variables and data types
- Loops (for, while, foreach)
- Classes and objects
- Structs
- Inheritance and polymorphism
- Static classes and methods
- Lists and arrays
- Pointers and references
- Linked lists (custom implementation)
- File input/output (read/write room data from file)
- Data structures (conceptual overview)

---

## Text Adventure Template — Design Goals

The template provides:
- Image display area
- Description text panel
- Options display (clickable choices)
- Text input field (for typed commands)

Students are responsible for:
- Defining a `Room` struct (name, description, connections, items)
- Building a linked list to connect rooms
- Writing an inventory/item system
- Loading room data from a file
- Extending gameplay logic
